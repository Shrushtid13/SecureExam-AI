# SecureExam AI

SecureExam AI is a highly advanced, automated remote proctoring platform that integrates real-time machine learning (ML), a strict browser environment extension, and asynchronous AI microservices to ensure absolute academic integrity.

## Architecture

The platform uses three independent data paths for proctoring:
1. **Client-Side Real-Time (ML):** MediaPipe Face Landmarker runs locally in the browser to track face count and head-pose (gaze) with a short grace-period mechanic.
2. **Browser Extension (Deterministic):** A strict Chrome extension utilizing `chrome.tabs` and `chrome.windows` APIs to instantly flag tab-switching or window-blurring events.
3. **AI Microservice (Asynchronous):** Periodic webcam snapshots and audio segments are sent to a FastAPI microservice (YOLOv8n + audio processing) for object and anomaly detection. 

Analytics are heavily cached via Redis for performance, and raw media evidence is stored in MinIO.

## Prerequisites

Before running the project, ensure you have the following installed:
- **Docker** and **Docker Compose**
- **Node.js** (v18+) (optional, for running tools locally outside Docker)
- **Google Chrome** (required for the proctoring extension)

## Quick Start (Docker)

The entire stack is containerized and orchestrated via Docker Compose.

1. **Clone the repository and navigate into it:**
   ```bash
   git clone <repo-url>
   cd "SecureExam AI"
   ```

2. **Start the platform:**
   ```bash
   docker compose up --build -d
   ```
   This will bring up the following services:
   - **Postgres DB** (`db` - port 5432)
   - **Redis Cache** (`redis` - port 6379)
   - **MinIO Storage** (`minio` - port 9000 & 9001)
   - **FastAPI AI Service** (`ai-service` - port 8000)
   - **Node/Express Backend** (`backend` - port 5000)
   - **React/Vite Frontend** (`frontend` - port 5173)

3. **Access the Application:**
   Open your browser and navigate to: `http://localhost:5173`

4. **Stop the platform:**
   ```bash
   docker compose down
   ```

## Setting Up the Chrome Extension

To take an exam, a student **must** have the SecureExam Chrome extension installed.

1. Open Google Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** in the top right corner.
3. Click **Load unpacked** in the top left corner.
4. Select the `extension` folder located inside the `SecureExam AI` directory.
5. Once loaded, copy the **Extension ID** generated by Chrome.
6. Open `frontend/.env` (create it if it doesn't exist) and set the ID:
   ```env
   VITE_EXTENSION_ID=your_copied_extension_id_here
   ```
7. Restart the frontend container or rebuild the frontend so it picks up the new environment variable.

## Features

- **Exam Builder:** Create Objective (MCQ, True/False, Numeric) and Subjective exams.
- **Auto-Grading:** Objective questions are instantly graded upon submission.
- **Granular Analytics:** Dashboard visualizes score distributions, class averages, and chronologically tracks integrity flags with photographic evidence.
- **Forgot Password:** Functional password reset flow using secure cryptographic tokens.
